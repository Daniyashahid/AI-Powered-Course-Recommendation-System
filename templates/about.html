About SmartCourse


Learn how SmartCourse uses AI to deliver intelligent course recommendations


Project Overview

SmartCourse is an AI-powered course recommendation system designed to help students discover the most relevant courses using advanced Natural Language Processing (NLP) and Machine Learning. It combines keyword-based (TF-IDF) and semantic (Neural Embedding) models to provide accurate, context-aware recommendations.

System Capabilities

🔍 TF-IDF Model

Finds courses based on exact keyword matching for accurate, context-relevant results.

🧠 Neural Model

Uses deep learning and sentence transformers for semantic understanding of queries.

📊 Personalized Results


Generates unique, preference-based recommendations with relevance scores.

Technical Implementation

🧩 Backend

Python (Flask), REST API

🤖 ML/NLP

spaCy, Sentence-Transformers, scikit-learn

💾 Database

SQLite for storing user history & saved results

🎨 Frontend

HTML5, Bootstrap 5, JavaScript (Fetch API)

Why Model Comparison?

The purpose of using two different recommendation models is to highlight how identical user queries can produce different results based on underlying techniques. TF-IDF focuses on exact keyword matching, while the Neural model captures semantic meaning and contextual similarity. This comparison helps users understand the strengths and limitations of each approach in real-world recommendation systems.


System Workflow

  1. User enters a natural language query
  2. Selected model processes the query
  3. Relevant courses are ranked using similarity scores
  4. Results are displayed with relevance percentages
  5. User actions (search, save) are stored in SQLite database

Dataset Information

SmartCourse uses the Course Recommendation System Dataset containing over 8,500 courses with details like:


  • 📘 Course Name
  • 🏛️ University
  • 🎯 Difficulty Level
  • ⭐ Course Rating
  • 🧾 Course Description
  • 🏷️ Department
